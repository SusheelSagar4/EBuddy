# Persona Specification: core_to_mba

## 1. Archetype
- **Goal:** `GOAL_MBA_CAT`
- **Who:** B.Tech EE or MME student at IIT Bhubaneswar considering a management career (CAT and similar entrances) alongside the degree, building on the engineering foundation.
- **Eligibility:** Open to B.Tech EE/MM students. The Core-to-MBA module holds the adaptive QA/DILR/VARC diagnostic, profile audit, mock calibration and shortlist; cut-offs are shown only from verified rows.

## 2. What the planner does for this persona
- Degree courses are planned first for every remaining semester (prerequisites, credit caps, backlogs).
- Goal milestones from `milestones.yaml` are placed in their target semesters; detailed exam tooling lives in the dedicated module named above.
- A phase or skill counts as *demonstrated* only on assessed evidence (timed quiz, rubric project, mock interview). Self-declared interest is weak evidence and never skips content.

## 3. Files
`persona.yaml`, `requirements.yaml` (mirrors `kb.goal_skill_requirement`), `mastery.yaml`, `milestones.yaml`, `diagnostic.yaml`, `policy.py`.

## 4. Data status
All rows are `draft_for_review`. Placement and admission dates, cut-offs and fees are never stated from memory; unverified facts are shown as "not confirmed yet".
